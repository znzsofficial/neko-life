# Management workspace extension

Mode: Operate. This is a narrowly specified extension of the existing MaiBot
declarative plugin workspace, not a new visual world or independent dashboard.

## Direction contract

THESIS: show what Life actually attempted and why; never reduce readiness to an
optimistic enabled badge.

OWN-WORLD: inherit MaiBot's built-in text/table widgets, theme, system fonts,
focus treatment and responsive scrolling; no custom palette, CSS or decorative
cards. Runtime semantics are this extension's responsibility, rendering is the
host's.

STORY: the operator first reads enabled/error/next eligibility, then checks the
fictional schedule, exploration audit and source notes, finally budget usage.

FIRST VIEWPORT: compact status lines with explicit unknown monetary cost,
followed by the current role activity and schedule table. Commands/settings
remain the route to pause/configure; the one confirmed exploration action is
real, starts only a notes job and is not an automatic QQ-send control.

FORM: extension inside established host workspace, fixed by approved plan; no
concept tournament or new frontend scaffold.

FINISH: record the finish review and inherited host ownership; this extension
does not create a separate DESIGN.md, token system, visual identity or raster.

No raster ships. Schema/private query checks and desktop/mobile top/bottom
inspection are complete. Independent finish review returned SHIP at the narrow
extension scope, not measured contrast/accessibility or whole-host certification.

## Verified extension behavior

The real host workspace was inspected at 1440px and 390px, at the top and
bottom of its scroll container. Body width stays within each viewport. Long
note text and source URLs now use full-width paragraphs instead of narrow
multi-column cells, and status/quota copy is readable Chinese. Host typography,
colors, navigation, focus and theme rendering are unchanged; no new visual
world or raster asset is introduced. The existing host mobile activity bubble
can overlap the lower edge temporarily; it is outside this extension's source.

Authentication was confined to an ephemeral browser context reached by a
temporary SSH forward. No access token, cookie export or login screenshot is
part of source, test fixtures or documentation. Screenshots with live operator
context remain local temporary evidence, not release assets.
