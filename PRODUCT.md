# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

The existing MaiBot operator reviews the plugin's background work, evidence,
budgets and failure states. Ordinary chat users do not receive this admin page.

## Product Purpose

Make autonomous public research and fictional life scheduling understandable,
traceable and pausable, without replacing established execution plugins.

## Operating Context

This is a narrow declarative workspace extension inside the existing MaiBot
Dashboard, as approved in the implementation plan. The host owns routing,
authentication, responsive components, typography, colors and all interaction
chrome; this project does not create another frontend or visual identity.

## Capabilities and Constraints

Show real runtime state, schedule, recent exploration jobs, source notes and
reserved usage. Unknown cost is explicit, failed requests are not empty states,
and roleplay schedules are not real-world evidence. Pause/configuration/cleanup
remain in host settings and private administrator commands. One reviewed,
confirmed workspace action can explicitly start research that only saves notes.

## Evidence on Hand

Private status_v1 API and persisted jobs/notes/usage; no invented statistics,
customer claims, demo results or external raster assets.
